# Controls — proof the detector is live

These two files exist so that "**0 genai / 0 C2PA**" reads as a **finding**, not as a **silent tool failure**. This is the first thing a competent skeptic (rightly) checks: *did your grep return zero because there's nothing there, or because your command was wrong?*

## The two files

- **`positive_control.jpg`** — a synthetic 64×64 JPEG (generated with PIL, unrelated to any evidence file) into which **every marker the detector greps for** was deliberately written:
  - an account path `…OneDrive - DoD365-Joint\…` (via a comment field),
  - `genai.mil`,
  - `c2pa`,
  - `Adobe Photoshop` / `Adobe Illustrator` (`Software` / `CreatorTool`),
  - `Witness_01-UAPs-SCENE1`,
  - `autoGenerated`,
  - `Screenshot` (`UserComment`).
  Running the detector on it **must fire on all of them**.

- **`neutral_control.jpg`** — the same synthetic base with only benign camera EXIF (`Make/Model/DateTimeOriginal`) and a comment that contains **none** of the marker strings. Running the detector on it **must return zero everywhere**.

## What they establish

`reproduce.sh` runs the identical detector over the evidence **and** these controls, and asserts:

| Control | Expectation | Meaning if it fails |
|---|---|---|
| positive | genai>0, c2pa>0, account-path>0 (and more) | the detector is broken / patterns are dead → **every "0" on the evidence is worthless** |
| neutral | all markers = 0 | the detector false-positives → its non-zero hits on evidence are suspect |

Only when **positive fires** and **neutral is silent** do the evidence numbers mean what they say: the 6 NASA files really do carry the account path (6/6), the 8 FBI files really don't (0/8), and the 14 files really carry **no** `genai`/C2PA marker.

## Reproducing the controls from scratch (optional)

They were built dependency-light:
```bash
python3 -c "from PIL import Image; Image.new('RGB',(64,64),(90,90,90)).save('/tmp/p.jpg','JPEG',quality=90)"
exiftool -overwrite_original -Software='Adobe Photoshop 25.0 (Macintosh)' \
  -XMP-xmp:CreatorTool='Adobe Illustrator 30.1 (Windows)' -EXIF:UserComment='Screenshot' \
  -Comment='POSITIVE CONTROL markers: genai.mil c2pa Witness_01-UAPs-SCENE1 autoGenerated path=C:\Users\ControlUser1\OneDrive - DoD365-Joint\PositiveControl\AS12-46-6842.jpg' /tmp/p.jpg
```
The neutral is the same base with only `-Make/-Model/-DateTimeOriginal` and a marker-free comment. Their SHA-256 values are printed by `reproduce.sh` and listed in the pack's provenance output. Their pixels are irrelevant; only the metadata matters to a metadata detector.

## 1. Method (reproducible; controlled)

For each file: (1) acquire (re-download from war.gov, or bundled fallback), (2) `exiftool -a -G1 -s -json` (all tags; decrypts standard PDFs), (3) `shasum -a 256`. Raw-byte `grep -aoiE` is run **in addition** to the parsed dump, because a marker can live in a segment exiftool does not surface as a tag (see §5 — this is exactly what happened with `autoGenerated`).

**Positive/negative controls** (`controls/`) prove the detector is live: a synthetic file carrying every marker trips all of them; a clean synthetic file trips none. Reported **absences** are therefore validated *by construction*, not by a broken command.

**Provenance authentication.** Three images re-downloaded live from `war.gov` hashed bit-for-bit to the analysed copies; a second operator independently reproduced the catalogue file (modulo a UTF-8 BOM). The metadata therefore belongs to the **official production chain**, not a reprocessed copy. `war.gov` sits behind Akamai (HTTP 403 to many automated fetches); the honest reproduction path is browser re-fetch + hash-compare — the hashes are the anchor.

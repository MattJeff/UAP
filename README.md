**Purpose.** This pack is not built to *show you* a result. It is built so that a hostile party can *reproduce* it **without trusting the author** — re-fetch the files from `war.gov`, hash them, re-run the metadata extraction, and confirm both the Adobe-montage provenance and the **absence of any AI-generation marker**, with a **live detector proven by controls**.

## TL;DR — replay in two commands

From this directory:

```bash
# 1) hash-check the bundled copies against the manifest (offline, ~1s)
grep -vE '^#|^$' manifest.sha256 | shasum -a 256 -c -

# 2) full re-derivation: re-download from war.gov, verify, re-run exiftool, run the detector + controls
./reproduce.sh
```

`./reproduce.sh` prints a `PASS/FAIL` line per check and exits non-zero on any failure. Use `./reproduce.sh --no-download` to run entirely offline against the bundled copies. Requirements: `bash`, `curl`, `shasum`/`sha256sum`, `exiftool` (optional but recommended), `jq` (optional).

## ⚠️ Correction applied before sealing this manifest (read `CORRECTION.md`)

A naïve claim of "**0 occurrences of `generated`**" would have been **literally false** and is now corrected. Raw-byte grep finds the token `generated` in **7 of the 8 FBI files** — but exclusively as the substring of **`autoGenerated`**, an Adobe **Photoshop image-slice attribute** (part of the `Witness_01-UAPs-SCENE` slice records), which has nothing to do with AI. It does **not** appear in the 6 NASA files nor in `FBI-UAP-D021` (the one file with no metadata). The `reproduce.sh` detector therefore reports `gen=N(auto=N,other=0)` and asserts **`other = 0`** — i.e. every `generated` token is the benign slice attribute. This is the difference between a manifest that seals a false claim and one that seals a true, scoped one. Full write-up in `CORRECTION.md`.

**The exact, scoped AI-labelling verdict:**

The catalogue labels the orbs **"Digital Rendering"** (the server filenames literally read `..._Digital-Rendering_...`) and the NASA images **"archival photograph … modified from its original state"** — but it **never** labels anything AI/genai-generated. Therefore: *the montage is byte-proven; AI generation is neither present nor disclosed.*

## Provenance & the Akamai caveat (important for reproduction)

`war.gov` sits behind Akamai, which returns **HTTP 403** to many automated fetches (`curl`, `wget`, headless clients). `reproduce.sh` attempts a live re-download first and **falls back to the bundled copy only when blocked, printing `BUNDLED-FALLBACK` for that file.** This is by design and is the honest limitation: *"here are my files"* is contestable; *"go fetch them yourself and compare"* is not. If the automated fetch is blocked in your environment, re-fetch the manifest URLs **in a browser** (which carries a valid Akamai session) and compare the SHA-256 yourself — the hashes are the anchor, not our copies. The provenance was originally established this way: three images re-downloaded live matched bit-for-bit, and a second operator independently reproduced the catalogue file (modulo a UTF-8 BOM; `reproduce.sh` handles that for the CSV).
